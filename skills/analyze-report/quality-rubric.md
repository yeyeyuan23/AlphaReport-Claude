统一研究质量口径（所有来源、分析入口共用）：

分开判断研究方向相关性、贡献、证据质量和本次阅读置信度。来源平台、作者、机构、写作形式、是否学术发表、是否开源，都不能替代证据或直接决定等级。研究类型按内容确定：empirical（实证）、theoretical（理论）、methodological（方法）、review（综述）、commentary（观点），不是券商/社区等分发渠道。

先识别主要结论实际声称了什么，再选择验证要求；不能仅凭 research_type、标题或报告形式套用整套实验清单。empirical 也包括事实描述，不都在声称预测能力。按结论逐项匹配证据：

| 结论实际主张 | 应核对的验证依据 |
|---|---|
| 事实描述、统计汇总、历史跟踪 | 数据来源与观察时点、样本覆盖、单位与计算口径、表格与正文一致性，以及能否由给定数据复核。没有预测主张时，不要求训练/测试划分、样本外检验或预测显著性；这些缺失不能成为 validation=limited、质量或置信度下调的理由。 |
| 当前状态的估计或测算，例如基金仓位估算 | 输入数据、计算方法、假设、可核对的参考值与误差边界。区分估算与实际披露；“标注为测算/存在测算误差”本身不证明数值结论可信。即使没有声称优于其他方法，也要判断关键假设或误差无法核对是否限制该估计结论，据此评为 limited/unclear；若声称估计准确或优于其他方法，需有对应比较证据。状态估计不自动等于未来收益预测，不强求与主张无关的预测检验。 |
| 关联、同期变化或解释性观点 | 比较口径、样本与统计/论证依据；不能把相关性写成因果。未声称因果效应时，不强求因果识别；声称因果时按下一项检查。 |
| 因果效应或确定的机制归因 | 识别设计、成立假设、混杂因素及与因果主张相称的对照和稳健性证据；同期变化本身不足以证明因果。 |
| 预测能力、预测模型的优越性或未来泛化 | 与目标和预测时点一致的训练/验证/测试设计、合理基准、潜在泄漏、样本外表现及相应稳健性。历史描述或样本内拟合不能替代这些证据。 |
| 非预测方法的性能，例如优化精度、数值误差或运行效率 | 对应的目标与误差定义、可比基准、问题规模、实验设置或复杂度证明，以及比较条件。求解精度或速度优势不等于预测或收益优势，不自动要求预测任务的样本外检验。 |
| 可交易策略的收益、净收益或实际可执行性 | 可用信息与信号/交易时点、策略及回测规则、比较基准，以及与主张相称的成本、换手、滑点和执行约束。声称未来有效时还需检查泛化证据。仅列指数历史涨跌不等于声称策略可交易。 |
| 理论命题 | 假设、推导或证明、边界情形，以及结论是否只在命题条件下成立；不因没有收益回测降级。 |
| 综述、观点或方法提案 | 文献与论据是否支持其论证、设计是否自洽、与已有方法的比较是否准确。明确区分“提出方案”和“效果已验证”；未执行实验不能写成效果证据，也不自动使方案的论证无价值。 |

同一篇报告可能混合多类结论。validation 的 basis 要说明主要结论类型、相应验证要求及原文已提供/缺失的证据，分别判断历史描述、状态估计与预测、因果或策略效果主张。可直接核对的统计总量与未经充分核对的估计值应分开说明，不能只凭风险声明为估计值赋予 supported。不能因标题含“跟踪/周报/描述”就豁免后者，也不能把对未来适用性的未验证边界当作历史描述本身的证据缺陷。整体等级以主要结论是否得到相应证据支持为依据，不用有数据的描述掩盖缺乏验证的核心预测、估计或收益主张；次要估计存在局限也不自动使整篇的描述性主结论降级。

明确保留的统计范围不等于范围有缺陷。若结论只声称某个季度、固定样本的事实，证据支持这个范围且没有越界，scope 可以为 supported；无需覆盖所有时期或市场。真实的数据时点矛盾、口径不清、估算误差无法核对或过度归因仍须如实记录。

描述性结论的验证也需要实际核对：在判断“图表与正文一致”之前，检查相关正文、图表标题、列标题及脚注的日期、单位、样本与比较期。若给定文本存在冲突，逐项保留冲突位置与内容，说明影响哪些结论，不能笼统声称全部一致。即使可能只是排版或提取错误，也须标为待核对，不自行选择一个日期当作正确值；按其对主要结论的影响判断 validation、scope 与 confidence，次要表格问题不自动否定独立可核对的其他结论。数字已展示不等于原始数据已经独立核实。

quality_checks 恰好覆盖四个维度，各给出 status 和 basis（中文判断及原文依据、成立条件或无法核对之处）。status 为 supported（依据充分）、limited（有明确局限）、unclear（材料无法判断）或 not_applicable（不适用，说明原因）。依据可以是原文方法、节号或命题条件的准确转述，不强求逐字引文，不编造定位信息。
- method：问题、假设、方法与结论是否相符；实证看数据构造与时点，理论看假设与推导，综述/观点看论据和论证链。
- validation：按上表检查主要结论是否得到相应证据支持。描述性统计可由可追溯且口径一致的数据核对获得 supported，无需预测实验；预测、因果及策略效果仍须各自相应的验证。某项预测检验不适用，不等于 validation 整个维度不适用，也不代表该维度自动 supported。
- scope：是否保留样本、参数、市场、路径与比较条件，结论是否超出证据。仅涉及交易策略时才检查成本、换手和执行约束。
- reproducibility：数据、步骤、证明或实现细节是否足以核对；代码未开放本身不使研究低质。未知不是已证实的缺陷。

quality 分级：
- strong：核心方法、主要验证与适用范围的依据充分（method/validation/scope 为 supported）。允许如未开源、单一市场等已明确保留的一般局限，不要求没有缺点。
- sound：主要论证有依据且值得阅读，但部分验证或细节有限；不能只因来源或非金融实验降级。
- weak：原文有明确问题使主要结论缺乏支持，例如测试标签进入训练、基准不等价却宣称普遍优势、证明不满足命题假设。说明具体依据，不以“没找到”代替证据。
- unknown：缺失或不可读的关键材料使质量无法判断，保留待核验，不强行评为 weak。

confidence 表示本次阅读对判断的把握：high 需要核心方法、验证和范围都可核对，三个核心维度不能为 unclear；medium 表示部分判断仍待核对；low 表示重要部分无法确认。unknown 不得同时填 high。置信度不是论文正确概率，也不是独立复现结果。

边界例：同样的滚动样本外因子研究，无论在 arXiv、东方财富还是 BigQuant 出现，按相同设计检查；数据口径清楚、统计可核对且结论限定于观察期的资金跟踪，可以获得 supported 验证判断，不因没有样本外收益检验降级；同一报告若进一步声称资金流能预测未来收益，该主张仍须预测证据。理论证明清晰、假设和结论相符时可 strong/high，无需收益回测；只有缺失正文的摘要是 unknown，不能因机构声誉评高或因材料缺失评 weak。

优势和局限可为空，不为凑数编造问题。一般局限与 critical_concerns 分开；后者必须是有原文依据、能具体说明如何影响核心结论的明确问题。研究贡献单独说明，不能将“新颖”直接换成“质量强”。不生成数字总分或正确概率。
