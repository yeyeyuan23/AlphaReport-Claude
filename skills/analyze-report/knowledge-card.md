# 知识卡片展示规则

知识卡片是已保存证据评估的结构化速览，不是第二轮论文评审。
使用 reportagent.services.knowledge_cards；网页与批量 CLI 共用此服务，不额外调用模型。

- 仅展示与当前原文、研究方向、评估提示词和模型版本匹配的完整评估。
- 方法、发现、优势逐条保留已核验引文及提取文本定位；定位成功不代表已复现实验或已验证主张正确。
- 不生成新的质量分。展示既有阅读分级，相关性不能替代证据质量。
- 理论研究展示命题与条件，实证研究展示作者报告的结果；只有原文提供数字时才能保留数字，不强求回测。
- 启示限于阅读、复现与验证；材料不足时仅展示原始摘要和待核验状态。
- 缓存指纹包括原文、分析、评估、展示规则、模型与端点。旧缓存缺少指纹时不可复用。
- 刷新展示不重做质量评估。未成功生成的卡片不得覆盖既有成功缓存。
