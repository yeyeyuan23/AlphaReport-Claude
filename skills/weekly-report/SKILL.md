---
name: weekly-report
description: 汇总上周发表的量化金融论文，生成带原文和研报页面链接的周报，可预览或发送到已授权的飞书目的地。
---

按论文的发表日期筛选上一个完整 UTC 周（周一至周日），不要用入库日期替代。
读取 [briefing.md](briefing.md) 了解周报格式。查询、生成和发送使用
`reportagent.services.weekly_report`，不在入口里另写一套流程。

飞书机器人私聊可直接发送 `/weekly`：复用现有 CLI，在后台生成并发送到该会话；群聊不可用。与日报和单篇阅读共用任务锁。没有周内资料时回复暂无资料，不调用模型。此入口不自动采集，也不安装定时任务。

从仓库根目录预览：

```bash
.venv/bin/python -m reportagent.cli.weekly_report --dry-run
```

仅在用户已授权发送并指定或配置了目的地时，才去掉 `--dry-run`。
默认使用配置的 Python 模型 API 刷新过期的摘要相关性和最多 12 篇新全文评估，再按保存的证据确定性排版。已有有效评估不占预算；库中 arXiv 条目缺少全文时可补取 PDF。
`--no-llm` 只读取缓存，过期或缺失的全文评估显示待核验；相关性分数不能充当研究质量评分。
`--max-reviews` 控制本期全文评估数（1–12），`--force-review` 强制刷新。全周资料都纳入列表，未完成评估的内容不进入重点推荐。

重点推荐与日报共用阅读优先级标准：相关性至少6分、质量 sound/strong、评估把握 medium/high、无明确关键疑虑。普通局限、未单独列出优势或来源为券商/社区不直接阻止入选；保留局限与材料类型，最多5篇。
