---
name: weekly-report
description: 汇总截至报告前一天的七天公开发布的量化金融论文，生成带原文和研报页面链接的周报，可预览或发送到已授权的飞书目的地。
---

统一按 `published_date` 筛选截至报告前一天的七个自然日的资料，包含起止日期。不补造时刻或按时区换日，不用提交、页面修改、入库时间替代来源日期。arXiv 使用官网列表批次日期；东方财富、BigQuant 使用来源返回的发布日期。本地 PDF 仅有年/月或日期未知时不进入周报。缺全文、正文不可用或超过240,000字符的论文直接跳过，不进入周报或自动补抓队列，不列为待核验。08:00 和 09:00 是任务触发时间，不是筛选截止时刻。
读取 [briefing.md](briefing.md) 了解周报格式。查询、生成和发送使用
`reportagent.services.weekly_report`，不在入口里另写一套流程。

飞书机器人私聊可直接发送 `/weekly`：复用现有 CLI，在后台生成并发送到该会话；群聊不可用。与日报和单篇阅读共用任务锁。没有窗口内资料时回复暂无资料，不调用模型。此入口不自动采集，也不安装定时任务。

从仓库根目录预览：

```bash
.venv/bin/python -m reportagent.cli.weekly_report --dry-run
```

仅在用户已授权发送并指定或配置了目的地时，才去掉 `--dry-run`。
复用采集时保存且当前有效的相关性与全文评估，正式生成时调用配置的 DeepSeek 模型，按 [synthesis.md](synthesis.md) 将每篇已有评估压缩成一句话结论，不补下载全文或重新评判论文。`--dry-run` 默认只排版已有发现、不调用模型；加 `--with-summary` 可生成真实模型短结论预览，消耗额度但不发送。缺失、过期或未完成的评估显示待核验，交由后续采集任务处理，相关性分数不能充当研究质量评分。窗口内有效评估按研究方向展示，缺失或未完成评估列入待核验。

重点推荐与日报共用阅读优先级标准：相关性至少6分、质量必须为 strong、评估把握必须为 high、无明确关键疑虑。sound 或 medium 等其余可读研究归为值得浏览。普通局限、未单独列出优势或来源为券商/社区不直接阻止入选；保留局限；概览统计达标论文数量，正文不另设推荐清单。

周报使用独立的 `weekly_briefing` 版式，不拼接日报正文：按研究方向分组，每篇独立展示“一句话结论 + 下一行论文标题链接”，各篇之间留空行，不使用“依据：”前缀，不把多篇结论或链接拼成一大段。正文不另设重复的推荐清单；待核验项及未推荐数量放在末尾。结论只以已有评估为依据，不推断全行业趋势或虚构共识；不改写和覆盖已保存评估。

模型为每篇生成一句结论，目标30～60字、中英混排尽量控制在160字符内，保留必要条件，用直白文字表达，不堆公式。篇幅是编辑目标，不因个别句子稍长让整份周报回退。程序校验每篇恰好对应一条结论、编号属于当前方向、没有遗漏或重复。模型调用失败或引用不合格时明确提示；已有发现不超过160字符则直接逐篇展示，过长时只提示查看完整解读，不裁掉条件或回退成长段落。每篇标题链接始终保留，优先打开论文库详情，没有详情地址时链接来源页。
