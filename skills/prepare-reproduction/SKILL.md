使用 reportagent.services.reproduction。先有可用全文和当前有效的证据评估，再从原文提取复现所需事实。
网页“复现准备”或 CLI：
```bash
.venv/bin/python -m reportagent.cli.reproduction --report-id 1
```
`--dry-run` 不写数据库，但可能调用模型；`--force` 忽略旧准备卡重新提取。

卡片包括研究/预测目标、推断时可用信息、训练目标、数据与样本、训练验证测试划分、基准、评价指标、适用假设。
原文事实必须附可定位的连续引文；材料不足写待核查，不猜测作者的设置。
理论研究按假设、命题、证明依赖和反例检查准备，不强求训练/回测字段。
最小验证与否定条件单独标为建议，不能描述成作者做过的实验。默认不提供实盘配置建议。
缓存绑定原文版本、当前评估、模型与提示词；失败或源资料变化不能覆盖既有成功结果。
